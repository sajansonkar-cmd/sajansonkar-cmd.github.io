# sajansonkar-cmd.github.io

Personal portfolio website for **Sarjan Sonkar**, built using **HTML, CSS, and JavaScript** and hosted on **GitHub Pages**.

## Overview

This repository contains a single-page portfolio site that highlights:
- Profile and introduction
- Education and technical skills
- Project showcase
- Gallery section
- Certifications
- Contact and social links

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```text
.
├── index.html          # Main portfolio page
├── style.css           # Site styling
├── script.js           # Interactive behavior
├── certificates.html   # Certificates listing page
├── images/             # Gallery images
└── README.md
```

## Run Locally

This is a static website, so no build step is required.

1. Clone the repository
2. Open `index.html` in your browser

## Deployment

The site is deployed via **GitHub Pages** and configured for a custom domain using `CNAME`.
