# sajansonkar-cmd.github.io

Personal portfolio website for Sarjan Sonkar built with HTML, CSS, and JavaScript.

## Added simple text webpage feature

The site now includes a **Text Demo** section where a user can type text into a textarea and see it displayed instantly.

## Deployment (GitHub Pages)

This repository is already structured for GitHub Pages deployment.

1. Push changes to the default branch.
2. In GitHub, open **Settings → Pages**.
3. Set source to **Deploy from a branch** and choose the default branch (root).
4. Save settings and wait for the site to publish.
